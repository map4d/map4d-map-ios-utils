## Description

Utility Library for [Map4dMap DTQG iOS SDK](https://cocoapods.org/pods/Map4dMapUtilsDTQG).  
Contains:

- Marker Cluster: handles the display of a large number of markers

## Requirements

- iOS 12.0+

## Installation

Map4dMapUtils is available through [CocoaPods](https://cocoapods.org).  
To install it, simply add the following line to your Podfile:

```ruby
pod 'Map4dMapUtilsDTQG'
```
